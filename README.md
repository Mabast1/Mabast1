### 🧠 How I build AI systems

| Principle | In practice |
|---|---|
| **Evals before vibes** | Every agent gets a benchmark harness and a baseline before it reaches production |
| **Agents are distributed systems** | Explicit tool contracts, idempotent steps, retries, tracing, and human-in-the-loop checkpoints |
| **Retrieval is a data problem** | Chunking, metadata, and freshness decide RAG quality more than the model does |
| **Own the unit economics** | Token cost, latency, and fallback paths are design inputs, not afterthoughts |
| **Ship, then harden** | Thin vertical slices to production, then instrument and iterate on real traffic |
